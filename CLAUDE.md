# Snake

A Snake game in plain HTML, CSS and JavaScript. Read @intent.md for what we're building.

## Build plan
Follow @PLAN.md. It splits the work into 5 layers.
- Build only the layer asked for, one at a time.
- Each layer must end with its 10-second check working and `npm test` passing.
- After finishing a layer, update its row in the Status table in PLAN.md.
- If a decision in PLAN.md needs to change, update PLAN.md in the same change.

## Rules
- No frameworks, libraries or build tools. No outside links or requests (no CDNs, web fonts or analytics).
- Always show a plan and wait for approval before changing files.
- The player name is a nickname only. Never add real names, emails or other personal data to this repo.

## Tests
- Tests live in `tests/` and run with `npm test`.
